# LAKY — Portafolio

Portafolio personal de **LAKY**, Junior Developer especializado en plugins de Minecraft, configuración de servidores, desarrollo web y bots de Discord. Fundador de **HyperMC** y dueño de **AEVORYNTH Studio**.

## Ver en vivo

Publicado con GitHub Pages (activar en Settings → Pages → branch `main` → carpeta `/`).

## Contenido

- `index.html` — estructura de la página (hero, historia, experiencia, estudio, skills, contacto)
- `assets/style.css` — estilos (tema morado/negro/violeta)
- `assets/script.js` — animaciones (GSAP + ScrollTrigger) e interacciones
- `assets/img/` — banners y foto de perfil

## Stack

HTML5, CSS3, JavaScript, [GSAP](https://gsap.com/) + ScrollTrigger, Google Fonts (Space Grotesk / Outfit).
